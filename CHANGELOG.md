# Changelog

## 1.0.0 — 2026-11-06

- Laravel Flow integration for transitions and assignments.
- Immutable definitions, pending-branch status and scoped host authorization.
- Versioned, idempotent commands with audit receipts and after-commit events.
- Destination-authorized reassignment, plain-text messages and explicit run cancellation.
- Tailwind 4 history view and Laravel Fields action validation, with host Filament 5 forms.
- Reviewed history import with source mappings and immutable evidence.
- Bounded graph/JSON validation, batched definition checks and history writes, and detached immutable input values.
- Checked observer-veto rollback for receipts/messages, shared native identity validation, and verified new engine publications.
- Shape-preserving fingerprints with explicit saved-receipt compatibility, portable historical dates and timezone round-trip checks.
- Query-backed paginated history with bounded message previews, localization hooks, admission budgets, formatting and static analysis.
- Laravel 12/13 Testbench coverage for ownership, concurrency boundaries and failure recovery.

Requires PHP 8.3+ and Laravel Flow 2.2.
